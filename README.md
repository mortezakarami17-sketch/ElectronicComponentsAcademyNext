# آکادمی قطعات الکترونیک

پوستهٔ اولیهٔ فارسی و واکنش‌گرای آکادمی قطعات الکترونیک. پروژه با HTML، CSS و JavaScript ماژولار ساخته شده و به فرایند build یا وابستگی بیرونی نیاز ندارد.

## اجرای محلی

در ریشهٔ پروژه، سرور HTTP داخلی Python را اجرا کنید:

```powershell
python -m http.server 8000
```

سپس در مرورگر به نشانی زیر بروید:

```text
http://localhost:8000
```

اگر دستور `python` در محیط شما به Python 3 اشاره نمی‌کند، از این دستور استفاده کنید:

```powershell
py -3 -m http.server 8000
```

برای توقف سرور، در همان پنجرهٔ ترمینال `Ctrl+C` را بزنید. اجرای ماژول‌های JavaScript از طریق HTTP محلی انجام می‌شود؛ بازکردن مستقیم `index.html` با نشانی `file://` ممکن است به‌دلیل محدودیت مرورگر در بارگذاری ES Module کار نکند.

## وضعیت این اسکلت

در این مرحله پوسته، خوشامدگویی، ناوبری اولیه و کارت خانواده‌های قطعات فراهم شده‌اند. مسیر مقاومت‌ها به‌عنوان خانوادهٔ فعال معرفی شده و هفت خانوادهٔ دیگر وضعیت «به‌زودی» دارند. درس کامل، آزمون و محاسبه‌گر هنوز پیاده‌سازی نشده‌اند.
